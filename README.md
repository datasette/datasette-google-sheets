# datasette-google-sheets

A [Datasette](https://datasette.io/) plugin for importing Google Sheets into tables and exporting tables, views and queries to Google Sheets, either once or on a schedule. Credentials come from [datasette-google-auth](https://github.com/datasette/datasette-google-auth) and scheduled syncs run on [datasette-cron](https://github.com/datasette/datasette-cron). This is an early alpha under active development.
